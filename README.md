## Local Development

```bash
# Clone the repository
git clone https://github.com/amanpandey8120/portfolio.git
cd portfolio

# Serve locally (requires Node.js)
npx serve

# Or use any static server
python -m http.server 8000
```

Open `http://localhost:3000` (npx serve) or `http://localhost:8000` (Python) in your browser.
